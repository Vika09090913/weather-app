# 🐱 Cat Weather App

A simple and fun weather app that shows the current weather for any city, paired with cute cat illustrations.

## ✨ Features
- 🌦️ Current weather by city name
- 🐈 Cat illustrations that match the weather conditions
- ⚡ Powered by the free Open-Meteo API (no API key required)

## 🛠️ Tech Stack
- React (useState, useEffect, useRef)
- Open-Meteo API
- CSS
